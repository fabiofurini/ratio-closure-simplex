# Notazione e bibliografia

- `notation.tex`: simboli coerenti con `PAPER_LONG`, con `s_ij` riservato agli slack primali.
- `references.bib`: riferimenti effettivamente citati nel primo report didattico.

Il riferimento alle note storiche è attribuito all'archivio del progetto senza inventarne autore o data. I metadati del paper di Bland sono stati verificati sul sito dell'editore; Picard e Gallo–Grigoriadis–Tarjan sono ripresi dalla bibliografia fornita.

## File condivisi non creati

L'albero previsto dal piano elencava anche `mathematical_statements.tex`,
`algorithm_pseudocode.tex` e una cartella `figures/`. Non esistono perché non
c'è riuso effettivo: gli enunciati e lo pseudocodice vivono nel tutorial, dove
sono argomentati, e il report sperimentale non li ripete. Le figure del report
sono generate da `report/generated/*.dat` con pgfplots, quindi non c'è materiale
grafico condiviso da archiviare. La regola del piano è di creare directory e file
condivisi solo quando contengono materiale realmente riusato.
