# Implementazione

- graph.cpp: CSR, SCC, condensazione, scaling e ricostruzione del duale.
- basis_forest.cpp: adiacenze intrusive modificabili della foresta di base.
- engine.cpp: basi, pricing, direzioni, ratio test e pivot.
- ratio_closure.cpp: oracoli, cammino canonico e query alle capacità.
- certificates.cpp: verifiche senza riottimizzazione.
- io.cpp e main.cpp: parsing, configurazione, metadati e CLI.

Compilare dalla radice del progetto con CMake; gli output restano in build/.
